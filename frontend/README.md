# Quantum Railways

Quantum Railways is a responsive railway construction-planning frontend. Toggle proposed infrastructure connections, track construction cost against the global budget, and compare the static quantum model evaluation examples.

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run build
npm run lint
```

The construction budget, eight cities, twelve proposed connections, destination goals, route values, and model evaluation data are hardcoded in `src/data/routes.ts`. Construction cost refers only to building railway infrastructure.
